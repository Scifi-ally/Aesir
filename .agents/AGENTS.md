# Custom Project Rules

## UI Design & Aesthetics Rule
- **No card boxes, container panels, or borders in UI layouts**: Always use a borderless, flat single-color background (`#000000`) for all application views and pages.
- Avoid wrapping UI content in card backgrounds (`bg-[#0d1117]`, `bg-[#161b22]`) or adding rounded borders (`border border-[#30363d]`, `border-[#21262d]`).
